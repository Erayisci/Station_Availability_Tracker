İstasyon performansı — talep × arz

Tek başına "doluluk %" yanıltıcı. Yakındaki rakip istasyonlar boşsa yüksek doluluk fırsat sinyalidir; rakipler de doluysa zaten doymuş bir bölgedir.

effective_supply = nearby_stations × (1 − nearby_avg_util / 100)
demand_supply_ratio = utilization × 10 / (5 + effective_supply)

Michaelis-Menten: çevre dolu → arz azalır → oran yükselir → genişleme önceliği. Yakın istasyonlar boşsa skor düşer; orada yatırım gereksiz.

SkorYorumTavsiye
≥ 70Yüksek talep, az arzYeni istasyon kur
40–70Orta talep / az arzSoket ekle
< 40Dengeliİzle

Komşu hesabı — coğrafi katman

"Yakın" 3 km yarıçap. Haversine ile küresel mesafe, dış API çağrısı yok; o günün veri setiyle istasyon-istasyon hesap yapılır.

ZesStationPerformanceIndexService.java:369

private double computeNearbyAvgUtil(
        String stationId,
        Map<String, double[]> stationSpatial,
        double radius) {

    double[] self = stationSpatial.get(stationId);
    if (self == null) return -1.0;

    double sumUtil = 0.0;
    int    count   = 0;
    for (var e : stationSpatial.entrySet()) {
        if (e.getKey().equals(stationId)) continue;
        double[] other = e.getValue();
        if (haversineKm(self[0], self[1],
                        other[0], other[1]) <= radius) {
            sumUtil += other[2];
            count++;
        }
    }
    return count > 0 ? sumUtil / count : -1.0;
}

Neden API yok?

Tüm hesap aynı günün verisinden çıkar. Harici servis bağımlılığı sıfır → günlük ETL 26 sn'de biter.

3 km neden?

Şehir içi sürüş süresi ~6 dk; sürücü için "pratik alternatif" eşiği. Şehirlerarası yollar için ayrı parametre.

Tier eşikleri

FEW ≤ 2   MODERATE ≤ 5   MANY > 5 · efektif arz cinsinden

Doğrulama — her tahmin geriye dönük ölçülür

Tahmin servisi her gün dünün tahmini ile bugünün gerçeğini karşılaştırır. Aşağıdaki örnek skorlar 13 Haziran 2026 doğrulamasından (önceki gün tahmini × bugünkü gerçek; 1.796 istasyon). Tarih değiştikçe değerler de değişir.

MAE

3,44 pp

Ortalama mutlak hata. Yarınki doluluğu ortalama ~3,4 puan sapmayla tahmin ediyoruz (örn. gerçek %45, tahmin %42–%48). Naïve baseline: 5,48 pp.

R²

0,665

Modelimiz, istasyonlar arası doluluk farkının %66,5'ini açıklıyor. (1,0 = mükemmel; 0 = ortalama kadar; <0 = ortalamadan kötü.) Naïve "yarın=bugün" R²'si -0,169 → ortalamadan da kötü.

Bias

+0,10 pp

Sistematik sapma sıfıra çok yakın. Sürekli yüksek ya da düşük tahmin etmiyoruz.

R² = 1 − Σ(y − ŷmodel)² / Σ(y − ȳ)²   — modelin hatası vs. ortalama tahminin hatası

Dinamik fiyatlandırma

Bugün fiyat sabit. Yarınki doluluğu zaten tahmin ediyoruz. Aynı motora fiyat elastikiyeti ekleyince, sistem tek tek istasyonlar için saat-bazlı öneri fiyat üretebilir: talep dolu saatlerde dengele, boş saatlerde teşvik et.

Hedef 1 — Gelir

Boş kapasiteyi indirimle doldurmak, talep tavanını dengeli fiyat artışıyla yönetmek.

Hedef 2 — Deneyim

Zirve saatlerde kuyruk azaltma. Sürücü dolu istasyona gelmeden önce alternatif öneri görmüş olur.

Hedef 3 — Yatırım

Fiyat oynatamayacak kadar baskı altındaki istasyonlar "yeni istasyon" listesinin en başına otomatik düşer.

Temel formül

recommended_price = base_price × (1 + α × (forecast_util − target_util))

α = istasyon-spesifik elastikiyet katsayısı (geçmiş fiyat-talep çiftlerinden öğrenilir).
target_util = bölge için optimal doluluk hedefi (örn. %65 — kuyruk yok, ama atıl da değil).

public PriceRecommendation recommend(String stationId) {
    StationForecast  fc  = forecastService.latest(stationId);
    ElasticityCurve  el  = curveService.forStation(stationId);
    double           base = priceService.basePrice(stationId);
    double           target = TARGET_UTIL;  // 0.65

    // Talep yüksekse fiyatı artır, düşükse indir
    double gap   = fc.predictedUtil() - target;
    double ratio = 1.0 + el.alpha() * gap;

    // Güven aralığı: tahmin residual dağılımından
    double[] ci = fc.residualBand();

    return new PriceRecommendation(
        base * ratio,
        base * (1 + el.alpha() * (gap + ci[0])),
        base * (1 + el.alpha() * (gap + ci[1])),
        fc.confidence()
    );
}
